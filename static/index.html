📚 Starter templates

Ready-made checklists for property onboarding, sales, move-ins/outs, renewals, CAM reconciliation and budgets — with roles, due dates, estimates and order already set.

New checklist template

Tip: the quickest way is to set up one real project the way you like it (subtasks, checklists, “waiting on”), then click Save as template on it. Everything is copied. Below, use More… on any item to add checklist items, subtasks or ordering.

Add person

Add teammates by work email — their Blink account is found automatically, so you can assign them tasks before they ever sign in.

Admin = everything, plus this People page and Reports & backups. Manager = can create projects, assign/reassign tasks, edit templates, manage people. Staff = can see everything but only update their own tasks. Duplicate entry for the same person? Choose “Merge into …” on the extra row and click Remove — their tasks move over.

👥 Project roles

Roles each project can have. Template items can be assigned to a role instead of a person — when a project starts, those tasks go to whoever holds that role on that project. The default person is pre-filled on new projects.

🧪 Demo data

Load a realistic sample week to try every feature: 4 demo teammates, starter templates, 9 sample projects (incl. onboarding 777 E Sonterra Blvd), blocked tasks, @mentions, logged time, reminders and more. No Blink messages are sent while loading.

📊 Weekly summary

Sent in Blink every Monday morning to anyone ticked “Weekly summary” on the People tab: overdue, blocked and due-this-week tasks across the team.
